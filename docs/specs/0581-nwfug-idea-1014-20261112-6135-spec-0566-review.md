## Context

[SPEC-0566](./0566-nwfug-idea-884-20261103-d974-spec-0406-review.md) made
`H._campaign_history` (`src/nightwright/agentic/history.py:1122`) and
`history_cache.campaign_history` (`history_cache.py:3247`) refuse any campaign id that
`store._contained_campaign_dir` (`store.py:211`) rejects, and added the CLI helper
`_campaign_dir_exists` (`cli_campaign.py:29`). Its close-gate review (campaign
IDEA-1014-20261112-6135, filed as IDEA-1320) left six minor findings: two are a real
behaviour gap in `src/`, four are test-strength gaps.

| # | Finding id | What it says | What this spec does |
|---|---|---|---|
| 1-2 | `nwfu:2095ee2a215a` (adversarial, logic), `nwfu:18b903c97cc4` (adversarial, error handling) | One defect, reported twice. `_uncached_history_index` (`history.py:1201`) lists the campaigns root with `p.is_dir()`, which follows symlinks, then calls `_campaign_history` for each name. | 3 | `nwfu:b06530396aad` (test, AC4) | The CLI test covers an absolute path and a `../` path, never a symlink that escapes the campaigns root, so `_campaign_dir_exists` is only exercised through `_contained_campaign_dir`. | Test (Design 2). |
| 4 | `nwfu:eaa1d51792b3` (test, AC3) | With `cache=True`, "never reads outside state.json" is only proven by spying `H._json`; the cache path reads files through its own helpers. | Test (Design 3). |
| 5 | `nwfu:4b50ca1f9b23` (test, ValueError) | `test_campaign_history_confines_ids` matches only `"not found"`, not the exact `campaign <cid> not found`, and has no empty id or trailing-separator id. | Test (Design 4). |

## Goals / Non-goals

**Goals**
- The uncached history index, and every per-campaign listing in `history.py` that feeds
  `_campaign_history`, skips a symlinked campaign directory instead of raising, so cache on
  and cache off enumerate the same campaigns.
- Close the four test gaps above with assertions strong enough that the behaviour they name
  cannot regress silently.

**Non-goals**
- Changing what `_contained_campaign_dir` accepts or rejecting more ids than SPEC-0566 does.
- Changing the cached listing (`_live_campaign_ids`); it is the reference behaviour.
- Making `nw history <symlink-id>` succeed: a single named symlinked campaign dir that
  resolves outside the root stays "not found".
- Any new test module.

## Decision

Enumerate campaigns in `history.py` through one helper that returns only real directories,
not symlinks, matching `_live_campaign_ids`; use it in `_uncached_history_index` and in the
two `_campaign_history` global-record listings. Then tighten the four tests: an escaping
symlink case in the CLI test, a file-open spy that covers the cache path, exact-message and
edge-id assertions, and an assertion that the cache run takes the incremental `dec_tail`
branch. When a strengthened test finds that the code does not meet the claim, fix `src/` in
the same change.

## Design

1. **Symlinked campaign dirs in listings (`src/nightwright/agentic/history.py`).**
   Add `_campaign_dir_names(cfg) -> list[str]`: sorted names of entries of
   `store.campaigns_dir(cfg)` for which `entry.is_dir() and not entry.is_symlink()`;
   `[]` when the root is not a directory. Replace the `p.is_dir()` listings at
   `history.py:1201` (`_uncached_history_index`) and `:1162` (the `cids` fallback in
   `_campaign_history`, keeping its `[cid]` fallback when the root is missing) and audit
   `:381` and `:971` for the same pattern, switching them when they enumerate campaign
   directories. A symlinked entry is skipped silently: it yields no index row, no gap line,
   and no error, exactly as the cached listing already omits it.
   `_campaign_history` itself keeps raising for an explicitly requested escaping id.
2. **CLI symlink test (`tests/test_cli_campaign_history.py`).** Extend
   `test_history_rejects_escaping_campaign_ids` with `escape-link`, a symlink created under
   `invoke.root / "agentic" / "campaigns"` pointing at `outside`: same assertions as the
   other ids (exit 1, `campaign escape-link not found` on stderr, empty stdout for both the
   default and `--json` forms). Add a direct assertion that `_campaign_dir_exists(cfg,
   "escape-link")` is `False` and that `_campaign_dir_exists` is `True` for a real campaign.
3. **Cache-on file-open spy (`tests/test_history_fixture.py`,
   `test_campaign_history_confines_ids`).** Keep the `H._json` spy and add a second spy that
   records every path opened by `builtins.open`, `pathlib.Path.open`, `Path.read_text`,
   `Path.read_bytes` and `os.scandir`/`os.open`, resolved at call time. The final assertion
   is that no recorded path equals or lies under `outside` (the resolved symlink target),
   for both `cache=False` and `cache=True`. The spy is installed after the cache is
   constructed, so the assertion is about the rejected ids only.
4. **Exact message and edge ids (same test).** Replace `match="not found"` with
   `match=rf"^{re.escape(f'campaign {cid} not found')}$"` (`re.escape` is needed because
   ids contain `.` and `/`). Add the ids `""` (message `campaign  not found`),
   `"SPEC-0394-20261102-ae5b/"` and `"a/"` (trailing separator) to the id list. The valid
   id after the loop must still return its history.
5. **Incremental decision path (`test_decision_link_provenance_keeps_text`).** Record the
   arguments of each `HC._decision_records` call instead of just counting. In the cache run,
   assert at least one call reading `decisions.jsonl`, and that every such call has
   `start > 0` and `line_start > 0` (the `dec_tail` branch, `history_cache.py:2912`), so a
   full-file rebuild (`start` absent or 0, `history_cache.py:2944`) fails the test. The
   existing `bool(calls) is cache` and link assertions stay.
6. **Index regression tests (`tests/test_history_fixture.py`).** New test
   `test_history_index_skips_symlinked_campaign_dir`, parametrised over `cache` in
   `[False, True]`: add `escape-link` (symlink to `_outside_campaign(tmp_path)`) under the
   campaigns root; `H.history_index(cfg, now=HISTORY_NOW, cache=cache)` must not raise,
   must contain no row for `escape-link`, and its campaign ids must equal those of an index
   built without the link. A second assertion compares the cache-off ids with the cache-on
   ids, so the two paths cannot disagree again. A CLI case in
   `tests/test_cli_campaign_history.py`: `nw history --list` with `escape-link` present
   exits 0, lists the real campaigns and not `escape-link`.

## Alternatives considered

- **Catch the `ValueError` per campaign in `_uncached_history_index`** — hides a genuine
  failure for a real campaign behind the same exception, and leaves the other `is_dir()`
  listings inconsistent with the cache.
- **Make `_contained_campaign_dir` accept symlinks that resolve inside the root and list
  with it** — widens SPEC-0566's confinement rule and still differs from the cached listing.
- **Make the cached listing follow symlinks** — it would expose an escaping directory to
  the cache; the cached listing is already the safer reference.

## Acceptance criteria

- [x] `H.history_index(cfg, cache=False)` with a symlinked campaign dir (target outside the
      root) under the campaigns root returns without raising, with no row for it.
- [x] Cache-off and cache-on `history_index` return the same campaign ids in that setup.
- [x] `_campaign_history` for a real campaign still succeeds when such a symlink exists
      (the global-record listing skips it).
- [x] `nw history --list` with such a symlink exits 0 and omits it.
- [x] `nw history escape-link` and `nw history escape-link --json` exit 1 with
      `campaign escape-link not found` on stderr and empty stdout; `_campaign_dir_exists`
      is `False` for it.
- [x] `test_campaign_history_confines_ids` asserts the exact message
      `campaign <cid> not found` and covers `""`, a trailing-separator id and the symlink,
      for `cache` in `[False, True]`.
- [x] That test's no-read assertion covers file opens made by the cache path, not only
      `H._json`, for `cache=True`.
- [x] `test_decision_link_provenance_keeps_text` fails if the cache run reads
      `decisions.jsonl` from the start instead of from the stored offset.
- [x] No test module is added; existing modules keep their single speed-tier marker.

### As shipped

`_campaign_dir_names` in `history.py` replaces the three campaign enumerations (`_uncached_history_index`, the `cids` fallback in `_campaign_history`, `_records_all`). The `:381` listing is the runs directory and the `:971` listing was `_records_all`; only the latter was a campaign listing. The file-open spy also records `io`-level opens via `Path.open`/`read_text`/`read_bytes`, `builtins.open`, `os.scandir` and `os.open`.

## Rollout / migration

None. Behaviour changes only when a symlinked directory sits under the campaigns root, and
then only from "raises" to "skipped", which is what the cached path already did.
