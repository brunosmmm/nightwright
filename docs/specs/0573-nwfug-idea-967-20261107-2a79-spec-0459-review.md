## Goals / Non-goals

**Goals**
- The double-click test runs the real open-detail click handler (`DetailOpener.on_click`), and its waits use
  `pilot_until`, not a fixed pause.
- `prepare_queue_window` refuses, before writing anything, a copy that holds a symlink, a
  hardlinked file, or a path that resolves outside the copy.
- Every datetime in every matching file and every matching global-log record is checked,
  and the rewrite grammar is checked on crafted input.
- The unshifted-copy test checks painted idents, the size is pinned, and refusals are
  proven to leave the fixture and the copy byte-identical.

**Non-goals**
- No change to `src/nightwright/`, to the committed fixture, to `history_scale.py`, or to
  any other test module.
- No new test module and no new speed tier.
- No change to the window assignment, the anchor rule, or the datetime grammar (SPEC-0459
  Design §2 stays as shipped). SPEC-0459 is not edited.

## Decision

Keep the shift's behavior for a plain copy and add one guard in front of it: a link check
that runs after the anchors are read and before the first write, and raises `ValueError`
on any link. Refusing is chosen over writing through an atomic replace: a harness that
is handed a linked tree is misconfigured, and a loud failure beats a silent success that
leaves the linked file alone. Everything else is test work in
`tests/test_tui_fixture_harness.py`: each sampled assertion becomes an exhaustive one,
or one taken from the model's own painted rows, and the click test wraps the original
handler instead of replacing it.

## Design

### 1. Link guard in `tests/tui_harness.py`

`prepare_queue_window` gains a step between "read every anchor" and "write the first
shift" (the existing comment says anchors are read first so one bad campaign leaves no
partial shift; this keeps that property):

```python
def _refuse_links(data: Path, camps: list[Path], logs: list[Path]) -> None: ...
```

It raises `ValueError` naming the offending path when any of these holds, for every path
in the campaign trees (`rglob("*")`, directories included) and in the global logs
(`_global_logs(data)`, plus the `mailbox`/`escalations` directories those come from):

- `path.is_symlink()`: a link to a file or to a directory, inside or outside the copy.
  A campaign directory (`campaigns/<cid>`) that is a link is covered, as is `campaigns/`.
- `path.resolve()` is not equal to or under the resolved `data` directory.
- the path is a regular file with `st_nlink > 1` (a hardlink: its inode is shared with
  another name, so a write changes both).

`_shift_tree` does not follow directory links, since a link raised first. `_shift_file`
and `_shift_global` are unchanged. `fixture_cfg` copies with `shutil.copyfile`, so a
fresh copy has `st_nlink == 1` everywhere and the existing callers
(`test_tui_campaign_detail*.py`, `test_tui_campaign_runs.py`) are unaffected.

The guard runs before any write, so a refused call leaves the copy byte-identical.

### 2. Test changes in `tests/test_tui_fixture_harness.py`

The module keeps its one `pytestmark = pytest.mark.tui` (SPEC-0490); no module is added.

1. **Real click handler** (`6b873e6a6b2e`, `c687d39a4d50`). `QueueTable` defines no click
   handler of its own (`QueueTable(DetailOpener, DataTable)`, `queue_tab.py:39`):
   `QueueTable._on_click` is inherited from Textual's `DataTable` (cursor and hover
   only), and the code that opens the campaign on a double-click is
   `DetailOpener.on_click` (`campaign_detail.py:150`). The test therefore records clicks
   with `monkeypatch.setattr(DetailOpener, "on_click", wrapper)`, importing `DetailOpener`
   from `nightwright.tui.campaign_detail`. The original is captured before the patch;
   the wrapper appends the `Click` to `seen`, calls the original
   `DetailOpener.on_click`, and awaits the result when it is awaitable. The inherited
   `DataTable._on_click` is not patched or wrapped, so it runs once per click through
   Textual's MRO dispatch. `monkeypatch` restores the attribute, so the
   `try/finally: del` goes away. After `double_click` returns the test asserts
   `sum(event.chain == 2) == 1` with no pause (the wrapper sees every `Click`). The
   screen-stack assertions (`len == before + 1`, top is `CampaignDetail`, rest of the
   stack is `before`) wait with `pilot_until` and prove the original handler ran. There
   is no `pilot.pause` in the test outside `pilot_until`.
2. **Link refusal** (`2a3dbd2cd4be`, `30c40daaa1a8`). New tests build `fixture_cfg`,
   create the link, then assert `pytest.raises(ValueError)` and that `_hashes(data)`
   is unchanged and the outside target's bytes are unchanged. Cases: a campaign file
   replaced by a symlink to an outside file that holds an ISO timestamp; a hardlink
   (`os.link`) from a campaign file to an outside file on the same filesystem; a
   campaign directory replaced by a symlink to an outside directory; a global log
   replaced by a symlink; a symlink that points to another file inside the copy. The
   test fails, and does not skip, when the link cannot be made. `tmp_path` holds both
   sides, so it is one filesystem.
3. **Every matching line and every token** (`f261e321ccb0`, `531fd42e4a9a`). One test
   runs `prepare_queue_window` on a copy, taking each campaign's delta from the test's
   own `_anchor` before and after. For all eight campaigns it walks every file under the
   campaign directory and every global-log record whose `campaign` or `source.campaign`
   is that cid, and checks:
   - the token count is equal before and after;
   - each token moved by that campaign's delta, within 1 s (fractional seconds are
     dropped, so the difference is under 1 s);
   - a `Z` token ends in `Z` after, a token with a numeric offset keeps that offset, a
     token with no offset has none;
   - the bytes outside tokens are identical (the tokens are replaced with a placeholder
     in both texts and the results compared). This covers date-only strings, `duration_s`,
     costs, ids and cids.
   Lines that name no manifest cid stay byte-identical for every global log (as before).
   The token regex in the test is written separately from `tui_harness._ISO`.
4. **Grammar unit test** (`531fd42e4a9a`). `TH._shift_datetimes` is called on a crafted
   byte string with a fixed delta of `+1h30m`, holding: a `Z` token; `+05:30` and
   `-05:00` offsets; fractional seconds; a naive token; a token that crosses midnight and
   a month end; a date-only `2026-11-03`; a campaign id with an 8-digit date; a
   digit-adjacent `12026-11-03T01:02:03`; and a number-like `duration_s`. The expected
   bytes are written out in the test, so the test pins the re-serialization
   (`timespec="seconds"`, original offset, `Z` kept) and the untouched cases.
5. **Painted idents** (`4b4865b165c3`). `test_unshifted_copy_hides_closed_campaigns`
   builds a second copy in `tmp_path / "shifted"`, calls `prepare_queue_window` on it, reads
   the delivered rows with `AM.rows_from_payload(Q.dashboard_payload(...))`, and derives
   each painted ident with the existing `_clipped(row)`. It asserts that none of those
   eight idents, and none of the raw cids, appears in the unshifted copy's `visible_text`.
   The idents come from the model's rows, so the test does not duplicate `_cells`.
6. **Size** (`b2d6ee6e746b`). A test asserts `TH.SIZE == (160, 48)`. A helper checks
   `(app.size.width, app.size.height) == (160, 48)` inside the Pilot, and the Pilot tests
   `test_unshifted_copy_hides_closed_campaigns`,
   `test_shifted_queue_lists_every_fixture_campaign` and
   `test_double_click_dispatches_to_the_queue_table` call it.
   `test_shifted_queue_lists_every_fixture_campaign` also asserts `_ID_W == 30`, since the
   clipped ident it checks depends on that width.
7. **Refusal leaves bytes alone** (`f2fae714422b`). The refusal test hashes every file
   under `HS.FIXTURE_DIR` (relative path to sha256, including `MANIFEST.json`) before
   and after the three refusals and asserts the maps are equal. Each refusal uses
   `pytest.raises(ValueError, match=...)` with a different message fragment, so a
   refusal for the wrong reason fails. The empty data dir is still empty afterwards. A
   new case removes one manifest cid directory from a fixture copy, asserts
   `ValueError`, and asserts the copy's hashes are unchanged (no partial shift).

## Alternatives considered

- **Write through `os.replace` of a temp file** — it would not follow a symlink and it
  would break a hardlink, but it hides a misconfigured tree. A refusal says so.
- **Check links in `fixture_cfg` only** — `prepare_queue_window` takes any `cfg`, and the
  findings are about its writes, so the guard belongs there.
- **Compare painted text with a hard-coded ident list** — it duplicates the clip rule
  from `_cells`; the model's own rows do not.
- **Edit SPEC-0459** — it is `done`; AGENTS.md says to write a new spec for a change.
