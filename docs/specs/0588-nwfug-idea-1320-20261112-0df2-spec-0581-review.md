## Context

[SPEC-0581](./0581-nwfug-idea-1014-20261112-6135-spec-0566-review.md) made campaign
enumeration in `src/nightwright/agentic/history.py` go through `_campaign_dir_names`
(`history.py:968`), which lists only real campaign directories
(`p.is_dir() and not p.is_symlink()`). That matches the cached listing
(`history_cache._live_campaign_ids`). Its review left three minor findings (IDEA-1338, from
IDEA-1320):

1. **Spy never proven to fire** (`nwfu:c8212904cb5a`, `tests/test_history_fixture.py`,
   `test_campaign_history_confines_ids`). The file-open spy only asserts that `touched` holds no
   path under `outside`. It never asserts that `touched` is non-empty during a valid-id call, so
   a spy that records nothing (a wrapper that silently stops firing, an I/O primitive the
   production code does not go through) passes the test vacuously.
2. **In-root symlink untested** (`nwfu:1ec20056b086`, same module). Every symlink test uses a link
   whose target lies outside the campaigns root. `_campaign_dir_names` skips every symlink,
   including one that resolves inside the root, and no test pins that.
3. **In-root symlink listed one way, opened another** (`nwfu:a40f59f729f2`,
   `history.py:968`). `store._contained_campaign_dir` (`store.py:211`) accepts a symlink that
   resolves inside the campaigns root, so `nw history <alias>` opens the aliased campaign, yet
   the alias no longer appears in `nw history --list` or the index, cached or not. List and open
   disagree for that input.

The three are one change: pick one rule for symlinked campaign dirs in history, apply it to
listing and to open-by-id, and test it with a spy that is shown to work.

## Goals / Non-goals

**Goals**
- Listing and open-by-id in history agree on symlinked campaign directories, cache on and off:
  a symlink under the campaigns root, whatever it resolves to, is not a campaign.
- A test pins that rule for a symlink that resolves inside the root.
- The confinement spy test fails if the spy records nothing, and proves its outside-path
  predicate can match.

**Non-goals**
- Changing `store._contained_campaign_dir`, which other (write and CLI) paths share under
  SPEC-0431, or what it accepts.
- Changing `_live_campaign_ids`; it stays the reference behaviour.
- Supporting symlinked campaign aliases in history (listing them). They are rejected, not listed.
- A new test module, and changing `_campaign_dir_exists` or its other caller.

## Decision

Symlinked campaign directories are not campaigns **in history**. `_campaign_dir_names` already
skips them; make open-by-id do the same by adding a history-level check that treats
`campaigns_dir/<cid>` being a symlink as "campaign not found", in both the uncached and cached
paths. `_contained_campaign_dir` is untouched. The `nw campaign history` handler's not-found branch gets one extra condition so the CLI exits 1, not 2, for such an id (Design 7). This removes the list/open disagreement in the
direction that needs no change to the cached listing (the reference) and no new accepted
behaviour. In the test module, add one in-root-symlink test and harden the spy test so a vacuous
spy cannot pass.

## Design

1. **Helper** (`history.py`, next to `_campaign_dir_names`):
   `_campaign_dir(cfg, cid) -> Path | None`. It returns `store._contained_campaign_dir(cfg, cid)`
   only when that result is not None and `(store.campaigns_dir(cfg) / cid).is_symlink()` is
   false (checked with `is_symlink()`, which does not follow the link); otherwise None. The
   `cid` string is already validated by `_contained_campaign_dir` before the symlink check, so
   the second check cannot be reached with a separator or `..`.
2. **Uncached open**: `_campaign_history` (`history.py:1129`) calls `_campaign_dir` instead of
   `store._contained_campaign_dir`, keeping the `not root.is_dir()` check and the
   `ValueError("campaign <cid> not found")` text unchanged.
3. **Cached open**: `history_cache.campaign_history` (`history_cache.py:3249`) does the same
   through `H._campaign_dir`, before any cache or campaign file is touched, with the identical
   error text.
4. **Docstring** of `_campaign_dir_names` states the rule: a symlink is never a campaign in
   history, whatever it resolves to, and open-by-id obeys it.
5. **Spy hardening** in `test_campaign_history_confines_ids` (`tests/test_history_fixture.py`):
   with all spies installed, and before the invalid-id loop,
   - call `H.campaign_history(cfg, "SPEC-0394-20261102-ae5b", cache=cache)` and assert
     `touched` is non-empty and contains at least one path under the campaigns root (cache off)
     or under the campaigns root or `cfg["cache_dir"]` (cache on); then clear `touched` and
     `opened`;
   - run a control: `(outside / "state.json").read_text()` and `open(outside / "state.json")`
     must each append a path the final predicate would flag (assert the predicate returns True
     on `touched` after the control), then clear `touched`.
   The post-loop assertions are unchanged. The existing mutation-check style applies: replacing
   `record` with a no-op must make the test fail.
6. **In-root symlink test** (new, same module):
   `test_history_in_root_symlink_is_not_a_campaign`, parametrised over `cache` in
   `[False, True]`. It symlinks `campaigns/alias-link` to the real campaign dir
   `SPEC-0394-20261102-ae5b` (a target inside the root) and asserts: `alias-link` is not in
   `H.history_index(...)` for either cache mode and the id set equals the set before the link;
   `H.campaign_history(cfg, "alias-link", ...)` raises
   `ValueError("campaign alias-link not found")`;
   the real campaign still opens. These assertions stay in `tests/test_history_fixture.py`,
   which has no CLI runner.
7. **CLI exit code** (`cli_campaign.py:531`, the `except ValueError` branch of the `history`
   handler, `nw campaign history <id>`). Today the branch raises
   `click.ClickException("campaign <id> not found")` (exit 1) only when
   `not _campaign_dir_exists(cfg, campaign)`; otherwise it raises `click.UsageError(str(exc))`
   (exit 2 with a usage banner). `_campaign_dir_exists` (`cli_campaign.py:29`) goes through
   `store._contained_campaign_dir`, which accepts an in-root symlink, so with only Design 1-3
   `nw campaign history alias-link` would exit 2. Change only that condition to
   `not _campaign_dir_exists(cfg, campaign) or H._campaign_dir(cfg, campaign) is None`, so a
   symlinked `campaigns_dir/<id>` takes the same `ClickException(f"campaign {campaign} not found")`
   path (exit 1) as `escape-link`. `_campaign_dir_exists` itself and its other caller
   (`cli_campaign.py:702`) are not touched; `cli_campaign.py` is a touched module. A
   ValueError for a real directory still exits 2.
8. **CLI test** (new, `tests/test_cli_campaign_history.py`, which owns the `invoke` fixture and
   the `escape-link` CLI tests): `test_history_in_root_symlink_is_not_a_campaign_cli`. It
   symlinks `campaigns/alias-link` to a real campaign dir (`next(p.name for p in campaigns.iterdir()
   if p.is_dir() and not p.is_symlink())`) and asserts `invoke("history", "alias-link")` exits 1
   with `campaign alias-link not found` in `result.stderr` and no `schema` in stdout;
   `invoke("history", "alias-link", "--json").stdout.strip() == ""`;
   `invoke("history", "--list", "--json")` exits 0 with `alias-link` absent from the row ids and
   the id set equal to the real campaigns; `invoke("history", "--list")` exits 0 without
   `alias-link`; and `invoke("history", <real>)` still exits 0.

## Alternatives considered

- **List in-root symlinks, so list and open agree by inclusion** — rejected: it changes the
  cached listing, which is the reference, and `_live_campaign_ids` also keys cache invalidation
  and eviction on real directories, so aliases would need handling there; the duplicate rows
  (alias and target) are worse than not listing.
- **Reject symlinks in `_contained_campaign_dir`** — rejected: it is shared by non-history write
  paths (SPEC-0431) and changing it is outside a test-and-history follow-up.
- **Leave the asymmetry and only add a test** — rejected: the review reports it as a logic
  defect, and a test would pin an inconsistency.

## Acceptance criteria

- [ ] `H.campaign_history(cfg, "<symlink-to-in-root-dir>", cache=False)` and `cache=True` both
      raise `ValueError("campaign <name> not found")`.
- [ ] A symlink under the campaigns root that resolves inside the root appears in neither the
      uncached nor the cached `history_index` result, and a real campaign beside it still
      lists and opens.
- [ ] `nw campaign history <in-root-symlink-id>` exits 1 (the `ClickException` path at
      `cli_campaign.py:531`, not the exit-2 `UsageError`) with `campaign <id> not found` on
      stderr, also with `--json`; `nw campaign history --list` (plain and `--json`) with that
      symlink present exits 0 and omits it.
- [ ] `_campaign_dir_exists` is unchanged; a ValueError for a real campaign directory still
      exits 2.
- [ ] `store._contained_campaign_dir` is unchanged (its tests pass without edits).
- [ ] In `test_campaign_history_confines_ids`, a valid-id call under the spies leaves `touched`
      non-empty, and a control read of an `outside` path is flagged by the final predicate.
- [ ] With `record` replaced by a no-op, `test_campaign_history_confines_ids` fails for both
      `cache` values.
- [ ] With the symlink check removed from `_campaign_dir` (helper returns the contained dir
      regardless), `test_history_in_root_symlink_is_not_a_campaign[False]` and `[True]` fail.
- [ ] With the `or H._campaign_dir(...) is None` term removed from `cli_campaign.py:531`,
      `test_history_in_root_symlink_is_not_a_campaign_cli` fails (exit 2 instead of 1).

## Test plan

- **Automated tests**, in two existing modules (no new module, no second tier):
  - `tests/test_history_fixture.py` (module marker `pytestmark = pytest.mark.integration`
    already present):
    - `test_campaign_history_confines_ids[False/True]` extended per Design 5.
    - `test_history_in_root_symlink_is_not_a_campaign[False/True]` per Design 6 (API level:
      `H.history_index`, `H.campaign_history`).
  - `tests/test_cli_campaign_history.py` (module marker `pytestmark = pytest.mark.fast` already
    present; uses its `invoke` fixture):
    - `test_history_in_root_symlink_is_not_a_campaign_cli` per Design 8.
  - Run `python3 tools/test_tiers.py --check` (when `tools/test_tiers.py` exists); it must exit 0.
  - Run the affected tests: `python3 tools/affected_tests.py --run uv run pytest -q`, plus
    `tests/test_history_fixture.py`, `tests/test_cli_campaign_history.py` and any history cache
    test modules it selects.
- **Mutation checks** (record the result in the spec when done): no-op `record` -> confines test
  fails; remove the symlink check in `_campaign_dir` -> in-root API test fails; remove the
  `or H._campaign_dir(...) is None` term at `cli_campaign.py:531` -> the CLI test fails; restore all.
- **Manual verification**: in a scratch campaigns dir, `ln -s <real-campaign> alias-link`;
  `nw campaign history --list` omits `alias-link`; `nw campaign history alias-link` exits 1
  (check `echo $?`) with `campaign alias-link not found`; `nw campaign history <real-campaign>`
  still works.
- **Regression guard**: the existing `test_history_index_skips_symlinked_campaign_dir` (outside
  target), the CLI `escape-link` tests (`test_history_rejects_escaping_campaign_ids`,
  `test_history_list_skips_symlinked_campaign_dir`) and `_campaign_dir_exists`'s other caller
  (`cli_campaign.py:702`) pass unchanged; `python3 tools/spec_lint.py` exits 0.

## Rollout / migration

None. Behaviour change is limited to `nw campaign history <symlink-alias>`, which now exits 1 with
"not found" like the listing; no data moves.
